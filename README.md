# engie-landing-metas

Landing page for ENGIE's Mid-Year Goals Review registration. Employees can submit their progress and enter a raffle for match tickets. Built with HTML, CSS and JavaScript, connected to Google Sheets.

## Structure

```
engie-landing-metas/
├── index.html
├── assets/
│   ├── style.css
│   └── script.js
└── README.md
```

## Setup

1. The form submits data to a Google Apps Script Web App
2. Data is stored in a private Google Sheet
3. Hosted via GitHub Pages

## Deploy

Enable GitHub Pages in repo settings → Pages → Branch: `main` → `/ (root)`
